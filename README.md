# AstraAI

AstraAI is an AI-powered assistant built using Python, Streamlit, and Google Gemini API.

## Features
- AI Chat
- PDF Chat
- Image Analysis
- Resume Reviewer

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- PyMuPDF
- Pillow
- python-dotenv

## Run

pip install -r requirements.txt

streamlit run app.py
